# Akane Haven

A separate personal microsite dedicated to Kurokawa Akane from *Oshi no Ko*.

## Local preview

Open `index.html` in a browser.

## GitHub Pages

Create a repository named `Akane-haven`, upload this folder's contents to the repository root, then enable GitHub Pages from the `main` branch and `/root`.

Expected route:

`https://tsukasa1x01.github.io/Akane-haven/`

Replace the placeholder media and image assets with materials you own or have permission to publish.
